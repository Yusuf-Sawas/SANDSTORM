## 🌪️ SANDSTORM

**SANDSTORM** is a mobile-first, offline-ready AI engineering workspace designed to transform mobile devices into fully functional developer environments.

## 🚀 Key Features

* **Mobile-First Workflow:** Optimized for development on mobile and portable setups.
* **Offline-Ready:** Powered by Dexie.js (IndexedDB) for seamless local data persistence.
* **AI Agent Integration:** Multi-agent framework (Architect, Debugger) powered by FastAPI backends.
* **Modern Tech Stack:** Built with PWA techniques and lightweight frontend architectures.

## 🛠️ Tech Stack

* **Frontend:** PWA / HTML / CSS / JS / Dexie.js
* **Backend:** Python / FastAPI
* **Architecture:** Agentic Workflows & Local-First Storage
